# Μάθημα 7 — Σημειώσεις Εκπαιδευτή
**«Φτιάξε τη δική σου διαδραστική ιστορία!»** · 60 λεπτά · Ηλικίες 7–9

**Θέση στη σειρά:** Μετά τα παιχνίδια (Μ1–4) · Πριν το τελικό showcase (Μ8)  
**Προαπαιτούμενο:** Μαθήματα 1–2 (βασικά μπλοκ, `πες`, υπόβαθρα). Η **μετάδοση** από Μ3–4 βοηθά αλλά δεν είναι υποχρεωτική.

---

## Σε μια ματιά

| | |
|---|---|
| **Στόχος** | Απλή ιστορία όπου ο θεατής κάνει επιλογή και αλλάζει η σκηνή |
| **Ελάχιστο αποτέλεσμα** | 2 υπόβαθρα + 1 χαρακτήρας που μιλάει + 1 αλλαγή σκηνής |
| **Ιδανικό αποτέλεσμα** | 3+ σκηνές + 2 διαφορετικά τέλη + ήχος ή αλλαγή ενδυμασίας |
| **Νέες έννοιες** | Σκηνή · Διάλογος · Επιλογή · (επανάληψη) Μετάδοση |
| **Δεν χρησιμοποιούμε** | Βαθμολογία · Ζωές · `για πάντα` κίνηση · Φυσική πτώσης |

> **Γιατί ιστορία μετά από παιχνίδι;** Λιγότερα bugs, περισσότερη δημιουργικότητα, και τα παιδιά που κουράστηκαν από παιχνίδια συχνά **λάμπουν** εδώ.

- [ ] Ετοιμάστε **demo ιστορίας** 2–3 λεπτών (2 επιλογές, 2 τέλη) — `M7-Demo.sb3` ή δικό σας
- [ ] Starter `M7-Starter.sb3`: 2 υπόβαθρα + 1 χαρακτήρας, χωρίς τελειωμένη ιστορία
- [ ] Στον πίνακα: σχεδιάστε **δέντρο επιλογών** με χαρτί (βλ. παρακάτω)
- [ ] Αποφασίστε **θέμα ιστορίας** για όσους κολλήσουν: «Περιπέτεια στο δάσος» / «Διαστημόπλοιο» / «Μαγική πόλη»
- [ ] Ρυθμίστε Scratch σε **Ελληνικά**

**Διαφορά από παιχνίδι:** Σήμερα δεν «κερδίζουμε» — **αφηγούμαστε**. Πείτε το ρητά στην αρχή.

## Χρονοδιάγραμμα

| Χρόνος | Τμήμα | Στόχος |
|--------|-------|--------|
| 0–5′ | Hook — χαρτί & ρόλοι | Καταλαβαίνουν «επιλογή → διαφορετικό τέλος» |
| 5–15′ | Demo ζωντανά | Βλέπουν σκηνή + διάλογο + κλικ |
| 15–35′ | Χτίζουν ιστορία (3 σκηνές) | Ελάχιστο αποτέλεσμα |
| 35–45′ | Προσθέτουν επιλογή | 2 διαφορετικά τέλη |
| 45–55′ | Ήχος & δοκιμή | Παίζουν/διαβάζουν τη δική τους |
| 55–60′ | Αφήγηση & κλείσιμο | Κάθε παιδί «διηγείται» 1′ |

**Plan B:** Μόνο γραμμική ιστορία (3 σκηνές, χωρίς επιλογή) — αρκεί για επιτυχία.

## Αναλυτικό σενάριο

### 1. Hook — ιστορία στο χαρτί (0–5′)

Σχεδιάστε στον πίνακα:

```
        [Αρχή: Δάσος]
           /    \
    [Σπηλιά]  [Ποτάμι]
       |          |
   [Θησαυρός] [Γέφυρα]
```

**Πείτε:** «Σήμερα φτιάχνουμε ιστορία όπου **εσείς** διαλέγετε τι συμβαίνει — σαν βιβλίο που αλλάζει ανάλογα με την επιλογή σας.»

Ρωτήστε: «Ποιος προτιμά να γράψει ιστορία αντί για παιχνίδι;» (Μην αφήνετε τους λάτρεις των παιχνιδιών να νιώσουν «χαμένοι» — πείτε ότι στο Μ8 μπορούν να επιστρέψουν στο παιχνίδι.)

---

### 2. Demo — πώς δουλεύει στο Scratch (5–15′)

**Δείξτε 3 ιδέες (όχι 3 ξεχωριστά έργα — ένα demo):**

1. **Σκηνή** = `άλλαξε υπόβαθρο σε [δάσος]`
2. **Διάλογος** = `πες "Πού να πάω;" για 2 δευτερόλεπτα`
3. **Επιλογή** = `όταν γίνει κλικ σε αυτό το αντικείμενο` → `μετάδωσε [πήγαινε σπηλιά]`

**Ελάχιστο demo — Σκηνή (αντικείμενο Σκηνή, όχι γάτα!):**

```scratch
όταν γίνει κλικ σε πράσινη σημαία
άλλαξε υπόβαθρο σε [Υπόβαθρο1]
μετάδωσε [αρχή ιστορίας]
```

**Χαρακτήρας (π.χ. `Ήρωας`):**

```scratch
όταν λάβω [αρχή ιστορίας]
εμφανίσου
πες "Μια φορά, σε ένα μαγικό δάσος..." για 3 δευτερόλεπτα
πες "Πρέπει να διαλέξω: Σπηλιά ή Ποτάμι;" για 2 δευτερόλεπτα
```

**Κουμπιά επιλογής** — 2 μικρά αντικείμενα (`Κουμπί_Σπηλιά`, `Κουμπί_Ποτάμι`):

```scratch
όταν γίνει κλικ σε αυτό το αντικείμενο
μετάδωσε [πήγαινε σπηλιά]
```

```scratch
όταν γίνει κλικ σε αυτό το αντικείμενο
μετάδωσε [πήγαινε ποτάμι]
```

**Σκηνή — αντίδραση σε επιλογή:**

```scratch
όταν λάβω [πήγαινε σπηλιά]
άλλαξε υπόβαθρο σε [Σπηλιά]
μετάδωσε [σκηνή σπηλιά]

όταν λάβω [πήγαινε ποτάμι]
άλλαξε υπόβαθρο σε [Ποτάμι]
μετάδωσε [σκηνή ποτάμι]
```

> **Σημαντικό:** Κάντε κλικ στο **Σκηνή** (κάτω δεξιά) πριν γράψετε κώδικα υπόβαθρου. Πολλά παιδιά μπερδεύουν Σκηνή με χαρακτήρα.

---

### 3. Χτίσιμο ιστορίας — 3 σκηνές (15–35′)

**Βήματα πίνακα (ακολουθούν όλοι):**

| Βήμα | Τι κάνουν | Πού |
|------|-----------|-----|
| 1 | Προσθέτουν 2–3 **υπόβαθρα** (ζωγραφική ή βιβλιοθήκη) | Σκηνή → Υπόβαθρα |
| 2 | 1 **ήρωας** (ή 2 χαρακτήρες) | Νέο αντικείμενο |
| 3 | `όταν πράσινη σημαία` → 1ο υπόβαθρο + `μετάδωσε [αρχή]` | Σκηνή |
| 4 | `όταν λάβω [αρχή]` → `πες` την αρχή | Ήρωας |
| 5 | `μετάδωσε [σκηνή 2]` μετά τον διάλογο (ή με κλικ) | Ήρωας ή Σκηνή |

**Απλούστερη γραμμική έκδοση (Plan B):**

```scratch
// Σκηνή
όταν γίνει κλικ σε πράσινη σημαία
άλλαξε υπόβαθρο σε [Σκηνή1]

// Ήρωας
όταν γίνει κλικ σε πράσινη σημαία
πες "Σκηνή 1..." για 2 δευτερόλεπτα
περίμενε 1 δευτερόλεπτα
άλλαξε υπόβαθρο σε [Σκηνή2]
πες "Σκηνή 2..." για 2 δευτερόλεπτα
```

(Στη γραμμική έκδοση, `άλλαξε υπόβαθρο` μπορεί να είναι στον ήρωα — λειτουργεί, αλλά προτιμήστε Σκηνή αν προλάβουν.)

**Έλεγχος 20′:** «Πόσοι έχουν τουλάχιστον 2 διαφορετικά υπόβαθρα που εμφανίζονται;»

---

### 4. Προσθήκη επιλογής — 2 τέλη (35–45′)

**Οδηγία:** Φτιάξτε 2 κουμπιά (ή 2 χαρακτήρες-επιλογές) που στέλνουν **διαφορετική μετάδοση**.

| Αντικείμενο | Κώδικας | Αποτέλεσμα |
|-------------|---------|------------|
| `Επιλογή_Α` | `όταν κλικ` → `μετάδωσε [τέλος Α]` | Χαρούμενο τέλος |
| `Επιλογή_Β` | `όταν κλικ` → `μετάδωσε [τέλος Β]` | Διαφορετικό τέλος |

**Ήρωας ή Σκηνή — τέλος Α:**

```scratch
όταν λάβω [τέλος Α]
άλλαξε υπόβαθρο σε [Χαρούμενο_τέλος]
πες "Ζήσαμε ευτυχισμένοι!" για 3 δευτερόλεπτα
παίξε τον ήχο pop
```

**Μπόνους:**
- `σκέψου "Μμμ..."` αντί για `πες` (σκέψη = συννεφάκι)
- `άλλαξε ενδυμασία σε [χαρούμενος]` πριν τον διάλογο
- `εξαφανίσου` χαρακτήρα σε σκοτεινό τέλος

---

### 5. Ήχος & δοκιμή (45–55′)

- Προσθέστε **1 ήχο** ανά σκηνή ή στο τέλος
- **Δοκιμή ως αναγνώστης:** Άλλο παιδί πατά πράσινη σημαία και ακολουθεί την ιστορία **χωρίς** να βλέπει τον κώδικα
- Διορθώστε: κείμενο πολύ γρήγορο → αυξήστε δευτερόλεπτα στο `πες … για`

---

### 6. Αφήγηση & κλείσιμο (55–60′)

**Δεν είναι παιχνίδι — είναι θέατρο:**
- Κάθε παιδί: 30–60″ «διήγηση» (εσείς ή φίλος πατάει τις επιλογές)
- Επαινέστε **ιδέα και χιούμορ**, όχι τεχνική τελειότητα
- **Προεπισκόπηση Μ8:** «Τελευταίο μάθημα — τελειώνετε το αγαπημένο σας έργο (ιστορία Ή παιχνίδι) και το παρουσιάζουμε!»

**Αποθηκεύστε:** `Όνομα_Ιστορία.sb3`

## Συχνά λάθη

| Πρόβλημα | Αιτία | Λύση |
|----------|-------|------|
| Δεν αλλάζει υπόβαθρο | Κώδικας στον χαρακτήρα αλλά λάθος σειρά | Βάλτε `άλλαξε υπόβαθρο` στη **Σκηνή** |
| Διάλογος δεν φαίνεται | `πες` χωρίς `εμφανίσου` ή χαρακτήρας κρυμμένος | `εμφανίσου` πριν το `πες` |
| Κλικ δεν κάνει τίποτα | Λάθος αντικείμενο επιλεγμένο | Κώδικας κλικ στο **ίδιο** αντικείμενο που κλικάρεις |
| Όλα τρέχουν μαζί | Όλα στο `όταν πράσινη σημαία` χωρίς `περίμενε` | Χρησιμοποιήστε `μετάδωσε` ή `περίμενε` ανάμεσα |
| 2 τέλη ίδια | Ίδια μετάδοση και στα 2 κουμπιά | Διαφορετικό όνομα μετάδοσης ανά επιλογή |
| Κείμενο στα αγγλικά | Αγγλικά στο demo | Αφήστε τα παιδιά να γράψουν στα Ελληνικά |

**Debugging για ιστορία:** «Ποιος μιλάει; Ποιος αλλάζει το φόντο; Τι γίνεται όταν κάνω κλικ;»

## Διαφοροποίηση

| Ομάδα | Στόχος |
|-------|--------|
| **7 ετών** | 2 υπόβαθρα + 2 `πες` + 1 κλικ (χωρίς πολλές μεταδόσεις) |
| **8–9 ετών** | 3 σκηνές + 2 τέλη + `σκέψου` ή ήχος |
| **Γρήγοροι** | 3+ κλάδοι, `άλλαξε ενδυμασία`, `ρώτησε … και περίμενε` για όνομα ήρωα |
| **Κολλημένοι** | Γραμμική ιστορία 3 σκηνών — **επαρκές** |
| **Λάτρεις παιχνιδιών** | «Η ιστορία σου μπορεί να έχει μάχη στο τέλος» — επιτρέψτε ήχους/δράση |

### `ρώτησε` (προχωρημένο μπόνους)

```scratch
όταν γίνει κλικ σε πράσινη σημαία
ρώτησε "Πώς σε λένε;" και περίμενε
πες (ένωσε "Γεια " απάντηση "!") για 2 δευτερόλεπτα
```

Χρειάζεται μπλοκ `ένωσε` (Τελεστές). Μόνο για παιδιά που έχουν ολοκληρώσει το ελάχιστο.
