
## Adults collection

Greek adult computer-skills course (24 lessons + teacher guide). Generated by `scripts/convert_adults.py` from `lesson-server/public/` (read-only source); verified by `scripts/check_adults.py` (text fidelity, exits non-zero on failure). All text is Greek and verbatim from the old pages.

### Files
- `src/content/adults/NN-slug.md` (24 files, `01-internet.md` ... `24-online-services.md`): one per lesson.
- `src/content/adults-guide/teacher-guide.md`: the 20-hour teaching sequence.
- `public/adult-materials/`: `lessons.js`, `lessons.css`, `programma-ergasias.pdf`, `paketo-exaskisis.zip` (copied; same relative paths as before).

### Lesson frontmatter
| field | meaning |
|---|---|
| `number`, `slug`, `title`, `goal`, `minutes`, `optional` | from old `lesson.json`. `slug` is the old folder name; the page URL must remain `/<slug>/` (teacher page `/<slug>/teacher-notes.html`). `optional` is true for lessons 21-24. `goal` has no "Στόχος: " prefix; the layout prints that label. |
| `exercise` | id of the interactive exercise in the body (see below) or `null` |
| `downloads` | site-absolute asset paths used by the lesson (`/adult-materials/programma-ergasias.pdf`, `.../paketo-exaskisis.zip`). Layout renders "download" buttons from these. |
| `tag` | header eyebrow, e.g. `ΜΑΘΗΜΑ 5 · 60 ΛΕΠΤΑ · ΓΙΑ ΜΑΘΗΤΕΣ` |
| `intro` | line under the header ("Διάβασε. Δοκίμασε. Βάλε ✓.") |
| `teacher_tag`, `teacher_title`, `teacher_goal` | teacher-page header (lesson 1's differ from student page; `teacher_goal` is verbatim, lesson 1 includes "Στόχος: ") |
| `teacher` | teacher notes as Markdown (`##` sections: Πλάνο 60 λεπτών / Πριν το μάθημα / Τι ελέγχω / Συχνή δυσκολία; lesson 1 has no headings) |
| `next_label` | only lesson 1: custom text for the "next lesson" link |

### Body conventions (student page)
Each old `<section class="card">` is a `##` heading plus content, in source order.
- Steps: numbered list; `> text` blockquote = old `<p class="help">` (class `help`, left border); `- [ ] text` = old per-step checkbox label. The layout must render these task items as `<label class="done"><input type="checkbox" class="step">text</label>` (lessons.js counts `.step` and writes the progress into `#progress`; lessons 2-24 use class `done` on the label).
- "Αρχείο εξάσκησης" and similar: a list of links (old `.bar` buttons: first is a download link, second opens the PDF in a new tab). Style as `.button` / `.button secondary`; add `download` or `target=_blank rel=noopener` as desired.
- Inline `<kbd>` and `<button>` are kept as raw HTML; `**bold**` = `<strong>`.
- Lesson 1 has the line `ΤΩΡΑ ΔΟΚΙΜΑΣΕ ΜΟΝΟΣ / ΜΟΝΗ` (old `.eyebrow`) before its last heading and a raw `<button id="reset">` (handled by the code appended to `public/adult-materials/lessons.js`).
- Layout must also supply: header (`tag`, `<h1>`, "Στόχος: goal", print button `data-print`, `intro`, `<p id="progress" class="status" role="status" aria-live="polite">`), the 3 nav links (Για μαθητές / Για εκπαιδευτές / Μαθήματα ενηλίκων), prev/next links by `number` (lesson 2's previous is 1; lesson 24 has no next), and load `/adult-materials/lessons.css` + `lessons.js` (defer). Raw HTML in the body must be allowed (Astro Markdown allows it).
- `public/adult-materials/lessons.css` additionally got `.eyebrow`, `.muted`, `kbd` rules (lesson 1 used to have them inline).

## Scratch & micro:bit collections

Generated by `scripts/convert_scratch.py` (helpers in `scripts/scratch_html.py`) from `lesson-server/public/` (read-only), the course originals in `scratch-course-7-9/`, and the Greek titles/goals/descriptions imported from `lesson-server/tools/prepare_scratch_course.py`. Verified by `scripts/check_scratch.py` (per-page text fidelity + sha256 of every linked file; non-zero exit on failure; run it with `-v` to print whitelisted boilerplate). Neither script deletes anything; re-running overwrites only its own outputs.

All frontmatter values are written as JSON (valid YAML), one key per line. All text is Greek and verbatim. Local links inside bodies and frontmatter are **site-absolute** (`/scratch-games/...`). Links to old pages keep their old `.html`/folder form (e.g. `/scratch-games/lessons/01-debug/teacher.html`, `/scratch-games/course/lesson-2.html`, `/microbit-emojis/teacher-notes.html`); Astro must emit pages at exactly those URLs (`build.format: 'file'` for the `.html` ones, or equivalent routes). The converter drops `target=_blank` and `download` attributes from converted links: the layout should open `http(s)` links in a new tab (`rel="noopener"`) and add `download` to links ending `.sb3 .zip .md .js` where the old page had them (all `.sb3/.zip/.md` download buttons and the `emojis.js` link).

### Static files (`public/`)
Every non-HTML file under the old `scratch-games/` and `microbit-emojis/` was copied byte-for-byte to the same relative path (134 files): `.sb3`, `.zip`, `.md` downloads (`Teaching-notes.md`, `Validation.md`, `lessons/teacher-notes.md`, `lessons/validation.md`, `course/files/*.md`), `assets/**/*.svg`, `lessons/NN-slug/{preview.svg,*-starter.sb3,*-complete.sb3,*-assets.zip}`, `lessons/catalogue.json`, `course/{games,starters}/*`, `course/games/LICENSE.txt`, `Scratch-*.zip`, plus the old stylesheets (`lessons/library.css`, `course/course.css`, `microbit-emojis/lesson.css`; reusable as style reference) and scripts `microbit-emojis/lesson.js` (designer) and `emojis.js` (JavaScript solution download).
