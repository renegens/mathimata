| | |
|---|---|

## Πριν το μάθημα

- [ ] Ανοίξτε έργα Μαθήματος 3 — **αν κάποιος δεν έχει έργο**, δώστε remix του demo σας αμέσως
- [ ] Ετοιμάστε **2 επίπεδα demo**: απλό (ζωές μόνο) και προχωρημένο (κλώνοι)
- [ ] Γράψτε στον πίνακα: «Σήμερα βελτιώνουμε — δεν ξεκινάμε από μηδέν»
- [ ] Αποφασίστε: κλώνοι **ή** αντιγραφή sprite (κλώνοι = μόνο για 8–9 ετών που είναι έτοιμα)

**Σημαντική προσαρμογή:** Αν η τάξη δεν ολοκλήρωσε καλά το Μ3, **μειώστε τις αναβαθμίσεις** σε: ζωές + game over μόνο. Μην πιέσετε κλώνους.

## Αναλυτικό σενάριο

### 1. Κίνητρο (0–5′)

**Πείτε:** «Δεν φτιάχνουμε νέο παιχνίδι — παίρνουμε το δικό σας και το κάνουμε **επαγγελματικό**!»

Δείξτε έργο Μ3. Ρωτήστε: «Τι λείπει; Τι θα σας ενοχλούσε αν το παίζατε 10 φορές;» (Απαντήσεις: πολύ εύκολο, δεν τελειώνει ποτέ, ίδιο κάθε φορά)

---

### 2. Demo αναβαθμίσεων (5–15′)

**Εξηγήστε 4 αναβαθμίσεις** (δείξτε, μην τα πείτε όλα μαζί):

| # | Αναβάθμιση | Εύκολο; |
|---|------------|---------|
| 1 | Ζωές (ξεκίνα από 3) | ★★☆ |
| 2 | Game over όταν ζωές = 0 | ★★☆ |
| 3 | Περισσότερα αστέρια | ★★★ |
| 4 | Ταχύτητα αυξάνει με βαθμολογία | ★★★★ |

**Κώδικας ΑΣΤΕΡΙ — όταν χάνεται (δεν το πιάνουν):**

Προσθέστε **μετά** το `επανάλαβε ώσπου` (όταν έφτασε κάτω):

```scratch
    εξαφανίσου
    άλλαξε [ζωές] κατά -1
    εάν <ζωές = 0> τότε
        μετάδωσε [τέλος παιχνιδιού]
```

**Κώδικας ΠΑΙΚΤΗ — game over:**

```scratch
όταν λάβω [τέλος παιχνιδιού]
σταμάτησε [όλα]
πες (ένωσε "Τέλος παιχνιδιού! Βαθμολογία:" [βαθμολογία]) για 5 δευτερόλεπτα
```

**Ζωντανή δοκιμή:** Παίξτε σκόπια χωρίς να πιάσετε αστέρια → οι ζωές μειώνονται → game over.

---

### 3. Κατασκευή (15–40′)

Δώστε **μενού επιλογών** — κάθε παιδί διαλέγει **τουλάχιστον 2**:

**Υποχρεωτικά (ελάχιστο):**
- [ ] Μεταβλητή `ζωές` = 3, ορατή στη σκηνή
- [ ] Μείωση ζωών όταν αστέρι φτάνει κάτω
- [ ] `μετάδωσε [τέλος παιχνιδιού]` + `σταμάτησε [όλα]`

**Προαιρετικά:**
- [ ] 2ο ή 3ο αστέρι (διπλασιασμός sprite — ευκολότερο από κλώνους)
- [ ] Διαφορετικός ήχος πιάσιμο vs. αποτυχία
- [ ] `άλλαξε εφέ χρώματος κατά 25` στον παίκτη όταν πιάνει
- [ ] Ταχύτητα `-8` αντί για `-5`

#### Κλώνοι (μόνο προχωρημένοι)

```scratch
όταν γίνει κλικ σε πράσινη σημαία
εμφανίσου
δημιούργησε κλώνο του [εαυτού μου]
δημιούργησε κλώνο του [εαυτού μου]

όταν ξεκινήσω ως κλώνος
πήγαινε σε θέση x: (επίλεξε τυχαίο -220 εώς 220) y: 180
... (ίδιος κώδικας πτώσης) ...
```

> **Συμβουλή:** Αν κλώνοι προκαλούν χάος, **σταματήστε** και χρησιμοποιήστε αντίγραφα sprite. Δεν είναι αποτυχία — είναι σωστή απόφαση εκπαιδευτή.

#### Ταχύτητα ανά βαθμολογία (μπόνους)

```scratch
    εάν <βαθμολογία > 10> τότε
        άλλαξε y κατά -8
    αλλιώς
        άλλαξε y κατά -5
```

---

### 4. Playtest & γυάλισμα (40–50′)

**Διδάξτε τη μέθοδο playtest:**
1. Παίξε 1 γύρο σαν παίκτης
2. Βρες 1 πράγμα που δεν σου αρέσει
3. Διόρθωσε ΜΟΝΟ αυτό
4. Ξαναπαίξε

**Συχνά bugs σε αυτό το στάδιο:**

| Bug | Διόρθωση |
|-----|----------|
| Game over αμέσως στην έναρξη | Ζωές ξεκινούν από 0 — όρισε `ζωές` σε 3 στην έναρξη |
| Ζωές μειώνονται όταν πιάνω αστέρι | Ο κώδικας απώλειας είναι μέσα στο λάθος σημείο — μόνο όταν φτάνει κάτω |
| Παιχνίδι δεν σταματά μετά game over | Λείπει `σταμάτησε [όλα]` |
| Πολλά αστέρια κολλάνε | Κάθε sprite χρειάζεται δικό του `όταν λάβω [πιάστηκε]` |

---

### 5. Επίδειξη & γιορτή (50–60′)

- 1′ demo ανά παιδί (ή ανά ομάδα 2 αν λίγος χρόνος)
- Ψηφοφορία: «Ποιο παιχνίδι θα παίζατε περισσότερο;»
- **Πείτε:** «Είστε δημιουργοί παιχνιδιών. Αυτό που φτιάξατε σε 4 ώρες, κάποιοι το κάνουν επάγγελμα.»

**Ιδέες για μετά τη σειρά:** power-ups · επίπεδα · διαφορετικό είδος παιχνιδιού (λαβύρινθος, κυνηγητό)

---

## Αναφορά — πλήρης αναβαθμισμένο αστέρι

```scratch
όταν γίνει κλικ σε πράσινη σημαία
εμφανίσου
για πάντα
    πήγαινε σε θέση x: (επίλεξε τυχαίο -220 εώς 220) y: 180
    επανάλαβε ώσπου <θέση y < -180>
        άλλαξε y κατά -5
    τέλος
    εξαφανίσου
    άλλαξε [ζωές] κατά -1
    εάν <ζωές = 0> τότε
        μετάδωσε [τέλος παιχνιδιού]

όταν λάβω [πιάστηκε]
εμφανίσου
πήγαινε σε θέση x: (επίλεξε τυχαίο -220 εώς 220) y: 180
```

### Παίκτης — game over
```scratch
όταν λάβω [τέλος παιχνιδιού]
σταμάτησε [όλα]
πες (ένωσε "Τέλος παιχνιδιού! Βαθμολογία:" [βαθμολογία]) για 5 δευτερόλεπτα
```

### Έναρξη παιχνιδιού (προσθέστε στον παίκτη ή αστέρι)
```scratch
όταν γίνει κλικ σε πράσινη σημαία
όρισε [ζωές] σε 3
όρισε [βαθμολογία] σε 0
```
