Οδηγός για να ετοιμάσετε τα αρχεία εκκίνησης **πριν** κάθε μάθημα.  
Τα έτοιμα αρχεία βρίσκονται στο φάκελο **`starters/`**:

| Αρχείο | Περιγραφή |
|--------|-----------|
| `M1-Starter.sb3` | Καθαρή γάτα, χωρίς κώδικα |
| `M2-Starter.sb3` | Γάτα με κίνηση + αντικείμενο `Μπάλα1` |
| `M3-Starter.sb3` | Παίκτης με βέλη + πέφτον `Αστέρι1` + βαθμολογία |
| `M3-Demo.sb3` | Ολοκληρωμένο ελάχιστο παιχνίδι (για επίδειξη) |
| `M4-Starter.sb3` | Πλήρες παιχνίδι με ζωές & game over |
| `M7-Starter.sb3` | 3 υπόβαθρα + Ήρωας + 2 κουμπιά επιλογής (χωρίς ιστορία) |
| `M7-Demo.sb3` | Ολοκληρωμένη ιστορία δάσους (για επίδειξη) |

> **Σημείωση:** Το `Αστέρι1` στα starters χρησιμοποιεί προσωρινή εμφάνιση — αλλάξτε την από τη βιβλιοθήκη Scratch (Fantasy → Star) πριν το μάθημα.

Για να ξαναδημιουργήσετε τα αρχεία: `python3 scripts/generate_starters.py`

Αν δεν ανοίγουν, ακολουθήστε τα βήματα παρακάτω χειροκίνητα.

**Γλώσσα Scratch:** Ελληνικά · **Χρόνος προετοιμασίας:** ~10–20 λεπτά ανά starter

---

## Γενικά (όλα τα μαθήματα)

- [ ] Scratch σε **Ελληνικά**
- [ ] Δοκιμή ανοίγματος κάθε `.sb3` σε έναν υπολογιστή της τάξης
- [ ] Αντιγραφή starters σε USB / κοινό φάκελο / Google Drive
- [ ] Εναλλακτικά: ανέβασμα στο Scratch ως **μη δημοσιευμένα** έργα και κοινοποίηση συνδέσμου «Δες μέσα»

### Ονοματολογία αρχείων

| Αρχείο | Περιεχόμενο |
|--------|-------------|
| `M1-Starter.sb3` | Καθαρό έργο — μόνο γάτα |
| `M2-Starter.sb3` | Γάτα με βασική κίνηση (από Μ1) |
| `M3-Starter.sb3` | Παίκτης + αστέρι (ημιτελές παιχνίδι) |
| `M4-Starter.sb3` | Πλήρες ελάχιστο παιχνίδι πιάσιμο |

## Μάθημα 1 — `M1-Starter.sb3`

**Σκοπός:** Τα παιδιά ξεκινούν καθαρά — χτίζουν τον κώδικα μόνα τους.

### Checklist κατασκευής

- [ ] Αρχείο → Νέο Έργο
- [ ] Μετονομασία αντικειμένου: `Γάτα` (δεξί κλικ → μετονομασία)
- [ ] Τίτλος έργου: `Starter Μάθημα 1`
- [ ] **Χωρίς μπλοκ** στην περιοχή σεναρίων (άδειο)
- [ ] Προαιρετικά: υπόβαθρο «Blue Sky» ή «Stars» για έμπνευση
- [ ] Αποθήκευση → `M1-Starter.sb3`

### Τι περιμένετε στο μάθημα

| Παιδί | Αποτέλεσμα |
|-------|------------|
| Ελάχιστο | 4 μπλοκ κίνησης |
| Τυπικό | + μωβ μπλοκ (πες / χρώμα) |
| Προχωρημένο | + βέλη ή 2ο αντικείμενο |

### Μετά το μάθημα

- [ ] Κάθε παιδί αποθηκεύει: `Όνομα_Μάθημα1.sb3`

## Μάθημα 2 — `M2-Starter.sb3`

**Σκοπός:** Ξεκινούν από κινούμενη γάτα — προσθέτουν βέλη & άγγιγμα.

### Checklist κατασκευής

- [ ] Ανοίξτε έργο Μαθήματος 1 (ή φτιάξτε νέο)
- [ ] Αντικείμενο `Γάτα` με αυτόν τον κώδικα:

```scratch
όταν γίνει κλικ σε πράσινη σημαία
για πάντα
    κινήσου 10 βήματα
    εάν σε όριο, αναπήδησε
```

- [ ] **Μην** προσθέσετε ακόμα βέλη — τα φτιάχνουν στο μάθημα
- [ ] Προσθέστε 2ο αντικείμενο: `Μπάλα1` ή `Αστέρι1` (από βιβλιοθήκη)
- [ ] Τοποθετήστε το 2ο αντικείμενο **δίπλα** στη γάτα (όχι επάνω της)
- [ ] Τίτλος: `Starter Μάθημα 2`
- [ ] Αποθήκευση → `M2-Starter.sb3`

### Checklist πριν την τάξη

- [ ] Επιβεβαιώστε ότι τα βέλη λειτουργούν στο πληκτρολόγιο
- [ ] Έχετε έτοιμο παράδειγμα **με** βέλη για επίδειξη (ξεχωριστό αρχείο `M2-Demo.sb3`)

### Μετά το μάθημα

- [ ] Αποθήκευση: `Όνομα_Μάθημα2.sb3`
- [ ] Σημειώστε ποιοι **δεν** έχουν βέλη (χρειάζονται βοήθεια στο Μ3)

## Μάθημα 3 — `M3-Starter.sb3`

**Σκοπός:** Παίκτης με βέλη + αστέρι — τα παιδιά ολοκληρώνουν το πιάσιμο.

### Checklist κατασκευής — Αντικείμενο `Γάτα` (παίκτης)

- [ ] Κώδικας βελών (υπόχρεωτος στο starter):

```scratch
όταν γίνει κλικ σε πράσινη σημαία
για πάντα
    εάν <πατήθηκε πλήκτρο δεξί βέλος;> τότε
        κινήσου 10 βήματα
    εάν <πατήθηκε πλήκτρο αριστερό βέλος;> τότε
        κινήσου -10 βήματα
```

- [ ] Μεταβλητή `βαθμολογία` (Για όλα τα αντικείμενα)
- [ ] `εμφάνισε μεταβλητή βαθμολογία` στη σκηνή
- [ ] **Χωρίς** ακόμα κώδικα `αγγίζει αστέρι` — το προσθέτουν στο μάθημα

### Checklist — Αντικείμενο `Αστέρι1`

- [ ] Προσθήκη από βιβλιοθήκη (κατηγορία Fantasy / Stars)
- [ ] Μέγεθος ~60–80%
- [ ] Κώδικας πτώσης (υπόχρεωτος στο starter):

```scratch
όταν γίνει κλικ σε πράσινη σημαία
εμφανίσου
για πάντα
    πήγαινε σε θέση x: (επίλεξε τυχαίο -200 εώς 200) y: 180
    επανάλαβε ώσπου <θέση y < -180>
        άλλαξε y κατά -5
    τέλος
```

- [ ] **Χωρίς** ακόμα `όταν λάβω [πιάστηκε]`
- [ ] Αποθήκευση → `M3-Starter.sb3`

### Checklist πριν την τάξη

- [ ] Έτοιμο **ολοκληρωμένο demo** `M3-Demo.sb3` (με μετάδοση `πιάστηκε`)
- [ ] Πίνακας με 2 στήλες: «Γάτα» | «Αστέρι1»

### Plan B

Αν πολλά παιδιά δεν έχουν έργο Μ2 → μοιράστε `M3-Starter.sb3` σε όλους.

### Μετά το μάθημα

- [ ] Αποθήκευση: `Όνομα_ΠιάσεΑστέρια.sb3`

## Μάθημα 4 — `M4-Starter.sb3`

**Σκοπός:** Πλήρες ελάχιστο παιχνίδι — τα παιδιά **βελτιώνουν**, όχι ξεκινούν από μηδέν.

### Checklist κατασκευής — Αντικείμενο `Γάτα`

```scratch
όταν γίνει κλικ σε πράσινη σημαία
όρισε [βαθμολογία] σε 0
όρισε [ζωές] σε 3
για πάντα
    εάν <πατήθηκε πλήκτρο δεξί βέλος;> τότε
        κινήσου 10 βήματα
    εάν <πατήθηκε πλήκτρο αριστερό βέλος;> τότε
        κινήσου -10 βήματα
    εάν <αγγίζει [Αστέρι1];> τότε
        άλλαξε [βαθμολογία] κατά 1
        παίξε τον ήχο pop
        μετάδωσε [πιάστηκε]

όταν λάβω [τέλος παιχνιδιού]
σταμάτησε [όλα]
πες "Τέλος!" για 3 δευτερόλεπτα
```

- [ ] Μεταβλητές `βαθμολογία` και `ζωές` ορατές στη σκηνή
- [ ] Μετάδοση `πιάστηκε` και `τέλος παιχνιδιού` δημιουργημένες

### Checklist — Αντικείμενο `Αστέρι1`

```scratch
όταν γίνει κλικ σε πράσινη σημαία
εμφανίσου
για πάντα
    πήγαινε σε θέση x: (επίλεξε τυχαίο -200 εώς 200) y: 180
    επανάλαβε ώσπου <θέση y < -180>
        άλλαξε y κατά -5
    τέλος
    άλλαξε [ζωές] κατά -1
    εάν <ζωές = 0> τότε
        μετάδωσε [τέλος παιχνιδιού]

όταν λάβω [πιάστηκε]
πήγαινε σε θέση x: (επίλεξε τυχαίο -200 εώς 200) y: 180
```

- [ ] Αποθήκευση → `M4-Starter.sb3`

### Checklist πριν την τάξη

- [ ] Ανοίξτε έργα Μ3 των παιδιών — όποιος δεν έχει, δώστε `M4-Starter.sb3`
- [ ] Έτοιμο `M4-Demo.sb3` με 2 αστέρια (για έμπνευση)

### Τι προσθέτουν στο μάθημα (επιλογή)

- [ ] 2ο αστέρι (αντιγραφή sprite)
- [ ] Διαφορετικοί ήχοι
- [ ] Ταχύτερη πτώση (`-8`)
- [ ] Μήνυμα τελικής βαθμολογίας με `ένωσε`

## Αντιμετώπιση προβλημάτων με starters

| Πρόβλημα | Λύση |
|----------|------|
| Το `.sb3` δεν ανοίγει | Ελέγξτε έκδοση Scratch 3 (όχι Scratch 1.4) |
| Ελληνικά μπλοκ δεν ταιριάζουν με τις σημειώσεις | Ρυθμίστε γλώσσα Ελληνικά πριν αποθηκεύσετε το starter |
| Τα παιδιά χαλάνε τον starter | Κρατήστε **master copy** — μοιράζετε ξανά στην αρχή κάθε μαθήματος |
| Χωρίς λογαριασμούς | Χρησιμοποιήστε μόνο «Αποθήκευση στον υπολογιστή» |

| Πότε | Τι |
|------|-----|
| **1 εβδομάδα πριν** | Δοκιμή Scratch στην τάξη |
| **2 μέρες πριν Μ1** | `M1-Starter.sb3` |
| **Μετά Μ1** | Φτιάξτε `M2-Starter` από καλό παράδειγμα μαθητή ή μόνοι σας |
| **Μετά Μ2** | `M3-Starter` + `M3-Demo` |
| **Μετά Μ3** | `M4-Starter` (ή χρησιμοποιήστε έργα παιδιών ως βάση) |
| **Πριν Μ7** | `M7-Starter` + `M7-Demo` |
